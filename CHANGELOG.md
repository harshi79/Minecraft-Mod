# Changelog

## 1.0.0

- Replaced the earlier Crystal Void concept with the new DDX56 Dark Medieval Castle add-on.
- Added craftable and command-obtainable DDX56 Castle Heart.
- Added lever-triggered, direction-aware castle generation.
- Added a furnished royal keep, defenses, survival rooms, courtyard features, crypt, treasury, and portal chamber.
- Added a gigantic rooftop Black Dragon block sculpture with extended wings and fire breath.
- Added original DDX56 textures and castle/dragon pack icon.
- Added Android-friendly staged construction and a packaged `.mcaddon` release.
